매매 화면은 기존 전체 자료 경로를 사용한다. 임대만 읽은 상태에서 매매로 바꾸면 빈 매매로 확정하지 않고 전체 자료를 조회한다. 로딩 중 빠른 왕복 전환도 요청세대/범위로 차단하며 같은 전체 범위인 건물↔토지 변경은 불필요한 읽기 취소를 하지 않는다. 캐시는 임대/전체 키로 분리하고, 확인된 메모·조건 저장은 양쪽 같은 원장만 수정, 구조변경/로그아웃은 양쪽 무효화. 기존 대표/찜/저장조건은 보존한다.
서버 스냅샷 빌드에서 gzip을 한 번 만들어 고정5MiB 파트로 원자 저장. 압축 producer/reader/upload를 backpressure로 연결해 전체 중복버퍼를 만들지 않음. 브라우저가gzip을 받을 수 있으면 보관한 압축바이트를 그대로 전송(encodeBody:manual, 보안헤더 래퍼도 같은 설정 유지), identity면 스트리밍해제. 기존 압축 안 된/옛 포맷 캐시도 호환. 중간 실패는 기존 완성 객체 보존/미완성 업로드 abort. JSON compact-v2 포맷표시가 있는 압축본만 바로 전송해 legacy검증 우회하지 않는다.
