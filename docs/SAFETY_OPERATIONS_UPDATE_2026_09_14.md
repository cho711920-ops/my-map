# 2026-09-14 기능·자료 보호·수집 운영 개선

## 반영 범위

디자인·사용방식 확장은 보류한다. 카드 배치, 색상·큰글씨, 검색조건 저장,
시장별 조건 기억, 찜 검색·정렬 확장, 선택바구니·임대 비교, CSS 전면 정리는
이번 변경에 포함하지 않는다. 기능 누락을 보완하는 입력·상태·검수 화면만 추가했다.

## 숫자와 안전 기준

- 날짜 합계는 한국 날짜의 시작일 기준, 출처·거래유형·같은 수집 범위의
  **최신 실행 1회**만 합산한다. 재시도 스냅샷을 중복 합산하지 않으며,
  재실행 이전 신규 건수까지 포함하는 일일 고유 신규 총계는 아니다.
- 공급처가 정확한 주소를 주지 않은 매물은 등록 보류다. 실제 조회·저장 실패와
  별도로 표시하며, 원본을 확인하지 않고 자동으로 지도에 공개하지 않는다.
- Windows 예약 스냅샷이 없거나 오래되면 미확인/오래된 확인값이라고 표시한다.
  확장 화면의 시간 변경으로 Windows 작업 예약까지 바뀌었다고 표시하지 않는다.
- 알림은 사용자가 켜는 선택사항이다. 반복 오류는 사유별 조치를 안내한다.
- 성능 계측은 현재 탭의 처리시간·오류 종류별 횟수만 저장한다. 서버로 전송하지
  않고 검색어·매물 ID·연락처·고객 정보·오류 메시지는 기록하지 않는다.
- 기존 공개 보류 19건, 기존 매물 ID·찜·메모·연락처는 일괄 변경하지 않는다.

## 배포 순서와 되돌리기

1. lint/typecheck, 전체 회귀, 실제 SQLite 전체 마이그레이션, Worker 빌드 검사.
2. D1 `0022_collector_automation_reports.sql`, `0023_quick_add_sale_details.sql` 적용.
   전자는 최소 실행 요약 테이블, 후자는 기본값 `{}`인 매매상세 열을 추가한다.
3. Worker·정적 웹을 함께 배포한다. 이어 설치된 확장 코드를 갱신한다.
   확장 1.1.9 / 네이버 6.0.4 / 당근 1.5.5 / 공실박스 2.2.7.
4. CI 브라우저 테스트는 localhost의 가상 자료만 사용한다. 운영 인증·외부 지도
   SDK·실제 공급처 수집 성공은 별도 운영 확인 대상이다.

문제 시 이전 Worker/정적 자산 버전으로 되돌리고 추가 테이블·열은 남겨두는
비파괴 복귀를 우선한다. DB 전체 시점 복원은 이후 정상 저장까지 취소하므로
별도 승인이 필요하며 자동으로 수행하지 않는다. 기존 설치 확장 코드도
프로필·로그인·설정과 분리해 백업한다.

## 검사 범위의 한계

브라우저 CI는 실제 검색·카드·상세·찜·시장·모바일·저장 모듈을 사용하지만
인증, 지도 SDK와 공급처는 격리 가상 경계다. 고객 한글 입력·초안·수집 통계는
별도의 VM/SQL/함수 회귀로 확인한다. 타입 검사는 전역 레거시 전체가 아니라
기존 층·확인매물 모듈에 빠른등록 가격·거래유형 계약부터 확대한 것이다.
속도 집계가 생겼다는 이유로 전체 사용자의 INP나 로딩 속도가 개선되었다고
단정하지 않으며, 측정 후 확인된 병목만 후속 최적화한다.
