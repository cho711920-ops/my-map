건물·토지매매 전용 수정창 v17 — 2026-10-19

사용자 제보
건물매매 목록의 수정 버튼이 기존 '매물 임대조건 수정' 창을 열어 매매가를 수정할 수 없고 임대용 필드만 보여 주었다.

적용
- 매매는 전용 수정창으로 분기하고 상가임대는 기존 창과 저장 경로를 유지한다.
- 건물: 매매가, 대지·연·전용·건축면적, 보증금 합계, 월 임대수입, 융자, 실투자금, 이자 차감 월수익, 기준 미확인 월수익, 광고 연 수익률, 건물 용도. 호실 매매로 확인되는 매물에만 매매 대상 층·호실 표시.
- 토지: 매매가, 토지면적, 지목, 용도지역, 도로접면, 형상. 건물 층수·임대료·권리금 필드 제외.
- 금액 만원, 면적 ㎡를 명시하고 면적 입력에는 평 환산 참고값을 표시한다. 빈 칸과 0원을 구분하며 기준 미확인 월수익을 월 임대수입으로 바꾸지 않는다.
- 최신 대표 관리값을 읽은 후 편집한다. 원본 참고값을 보충 표시하더라도 사용자가 바꾼 필드만 저장한다. 원본 광고·사진은 수정하지 않는다.
- 매매가와 매매 상세 필드를 전용 서버 검증으로 저장한다. 오래된 임대창으로 매매의 임대 금액·면적 컬럼을 잘못 변경하는 요청은 거부한다.
- 변경 필드에 최초 값과 최신 값을 비교하고 DB 원자적 조건부 갱신으로 동시수정 충돌을 막는다. 충돌 시 입력을 유지하고 최신 값과 비교 후 사용자가 재선택·저장한다. 자동 덮어쓰기나 자동 재시도는 하지 않는다.
- 직접 고친 상세 필드만 manualSaleFieldsV1으로 보호한다. 이후 수집에서도 해당 값과 명시적인 빈 칸은 유지하고, 수정하지 않은 면적·설명 등은 새 원본 정보를 계속 반영한다. 기존 전체 필드 보호 방식도 호환한다.
- 매물명·연락처·관리 상태·메모 및 기존 ID 기반 삭제 흐름을 유지한다. 수정 이력에는 매매가와 개별 상세 항목을 표시하며 원본 설명과 내부 보호 표시는 공개 변경목록에서 제외한다. 기존 관리자 선택 복원에 매매 필드도 연결했다.
- 기존 임대창의 지연 자동초점이 이미 입력 중인 다른 필드에서 초점을 빼앗는 현상을 함께 수정했다.
