v183 건물매매 상세카드 정리

사용자 요청/적용 범위
- 빨간 원: 대장 제원 확인 중복 버튼, 광고 원문 근거/별도 매매 상세 원문, 공적 층별/용도별 구성, 내부 토지정보·공시지가/주변 실거래 패널, 광고·공적 면적 계산 결과를 건물매매 상세카드에서 제거한다.
- 사진·선택 광고 매매가·보증금 합계·월 임대수입·단순 연 수익률·광고 실투자금(있는 경우)·광고 면적을 첫 요약에 모은다. 불명값은 미제공/산정불가, 금액0과 구분한다.
- 수집 메모/원문 접기/현황 초록 강조/개인 첨부(빨간 버튼·업로드 시각)/같은 건물의 정확 원본 광고와 광고 정리 기능은 보존한다.
- 계산창·검토서·선택 매물 비교·묶인 원본 광고 비교·호가 이력·원래 광고의 추가 조건은 닫힌 '매입 도구 · 추가 정보' 한 메뉴에 둔다. 원문 데이터/서버 기능/기존 검토 저장자료를 삭제하지 않는다.
- 건물매매에만 적용한다. 임대·토지매매의 기존 공적자료/계산 UI와 API는 그대로 둔다.

구현
- sale-property-workspace-v3의 건물매매 분기는 옛 공적자료/층별/근거 패널 및 5개 항목 탐색줄을 생성하지 않는다. wide-detail-v26의 건물 전용 요약을 사용한다.
- 광고 선택·saleSummary/displayPrice/saleYield·기존 면적 단위 변환을 사용한다. 임대수입·단위·수익률을 새로 파싱하거나 저장하지 않는다. 수집/대표 선택/목록 캐시/사진 다운로드/원장 쓰기 경로 변경 없음.
- 밸류맵/토지이음 각각 한 버튼. 사용자 클릭 시 즉시 분리된 새 탭을 확보하고 opener를 제거한 뒤 기존 exact parcel resolver로 주소를 검증한다. 주소가 정확하게 단일 필지로 확인될 때만 기존 검증 PNU 링크로 이동한다.
- 기본 목록/상세 표시 때 외부 조회나 지번 선조회 없음. 기존 지번 resolver의 주소별 합류/10분 캐시·8초 제한을 유지한다. 도로명/숨긴 번지/복수 필지/불일치는 추정해서 열지 않는다. 오류 시 임시 탭을 닫고 재시도 가능 상태/메시지 유지. 상세 교체·닫기·계정 변경 뒤 늦은 결과는 새 탭을 닫는다.
- 외부 링크는 기존 https://www.valueupmap.com/properties/lands/PNU, https://www.eum.go.kr/web/ar/lu/luLandDet.jsp?...&pnu=PNU. 2026-11-11 공식 밸류맵/토지이음 공개 홈페이지 확인. 로그인/유료·열람제한을 통과했다고 주장하지 않는다.
- 공개 배포 검증에 변경된 workspace/wide JS·CSS 3개를 추가한다. 총31자산+HTML, 양 도메인64응답.
