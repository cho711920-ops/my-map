HOLD-20261019-01 — 주거용 실거래 API 활용신청·연결
상태: 사용자 요청으로 보류 (2026-10-19 KST)
다음 작업 예정: 2026-10-20 KST, 사용자가 작업을 재개할 때 이어서 진행.
이 기록은 자동 실행·예약·재시도 승인이 아니다. 보류 중 로그인·신청을 다시 시도하지 않는다.

사용자 요청
- 다가구·주거용 매매 실거래 API를 추가하고 공공데이터포털 활용신청을 대신 진행.
- 사용자가 로그인을 승인했고 보안문자 대리 입력도 별도로 승인했음.
- 이후 사용자 지시: "이건 수정보류함에 넣어놔 내일 작업하자".

현재 상태
- 단독/다가구 매매 실거래 API: 국토교통부 / 자료번호15126465 / RTMSDataSvcSHTrade.
  https://www.data.go.kr/data/15126465/openapi.do
- 연립·다세대 매매(15126467), 오피스텔 매매 등은 매물 유형에 맞춰 기존 신청 여부부터 확인할 후보.
- 주거용 신규 활용신청은 제출·승인 완료를 확인하지 못했음. 완료로 보고하지 않는다.
- 로그인 양식 입력 후 제출을 시도했으나 로그인 성공을 확인하지 못했음.
  브라우저 입력 호환 오류와 무응답이 있었으며, 비밀번호 오류라는 안내는 확인하지 못했음.
- 실제 Windows 창 조작도 시도했으나 URL을 확실히 확인할 수 없어 안전 검사를 수행할 수 없다는
  자동 승인 검토 차단으로 컴퓨터 조작이 중단됨. 제한을 우회하거나 다른 조작 경로로 재시도하지 않음.
- 기존 토지(15126466)·상업업무용(15126463) 실거래는 별도 활용승인·서버 인증 연결 완료 상태.
  docs/sale-trade-key-connected-20261019.txt 참조. 기존 키를 다시 만들거나 교체할 이유는 확인되지 않음.
- 운영 코드에는 아직 토지/상업업무용 두 실거래 자료만 연결돼 있음. 주거용 연동 배포 없음.
- 아이디·비밀번호·인증키·세션·보안문자는 이 문서나 커밋에 저장하지 않는다.

내일 재개 순서
1. 컴퓨터 조작 가능 여부와 포털 로그인 상태를 새로 확인. 현재 브라우저 주소 안전 확인이 먼저다.
2. 기존 활용신청 목록을 확인해 중복을 피하고, 단독/다가구 매매부터 신청 및 승인 상태 확인.
3. 필요한 연립·다세대·오피스텔 등 주거 유형을 구분해 신청 범위를 확인.
4. 승인 후 기존 실거래 전용 서버 키로 해당 서비스가 정상 응답하는지 읽기 전용 검증.
5. 유형별 실거래 필드·조회 분기를 연결하고 총건수/해제·지분·불완전 응답/개인정보 표시를 검증.
   주거용 거래를 상업업무용 거래로 오인시키지 않고, 비공개 지번으로 정확한 거리·핀을 추정하지 않음.
6. 구현·검수·배포 단계와 신청 승인 단계는 별도로 브리핑.

관련 논의 — 아직 구현하지 않은 사항
- 상세 실거래 기간 확대, 비교 적합성·위치 정확도 표시, 메인 지도 실거래 레이어는 제안·브리핑 상태.
- 토지 지목·면적 누락도 원인만 확인한 별도 항목이며 이번 API 활용신청이 해결한 것으로 보고하지 않음.
