매매 검토 인쇄 보완 v22 — 2026-10-19

사용자 요청
- 건물매매 검토 인쇄물에서 출처를 제거하고 보증금·월세 등 매입 검토 정보를 보강.
- 화면 요약에 없고 설명에만 있던 금융조건도 선택 원본의 현재 응답으로 확인.

변경
- 매매 인쇄물의 연락처 행에서 출처 이름 제거. 기존 메모의 출처: 표기 정리 유지.
- 임대보증금 합계, 월 임대수입, 연 임대수입(월세×12), 보증금 차감 단순 연 수익률,
  광고 융자금·실투자금·월수익(이자차감/기준미확인 분리)·광고 연수익률을 먼저 배치.
- 대지/연면적/전용/건축면적과 대지·연면적 기준 매매단가, 용도/사용승인일/층·호실,
  수집된 세대·가구·방·욕실 수를 조건이 있는 경우 추가.
- 면적별 단가는 건물 총매매가 기준 비교값이다. 토지 자체 가격으로 표시하지 않음.
- 기존 목록의 선택 원본을 인쇄 직전 unifiedListingDetail 강제 새 읽기로 확인.
  v21 서버의 보증금·임대수입 보완 결과를 그대로 사용하며 별도 금액 파서를 만들지 않음.
- 원본ID 우선으로 정확히 같은 광고만 매칭. ID가 없으면 출처·가격·링크 일치의 유일한 후보만 사용.
  다른 광고 금액을 빌리거나 주소만 같은 원본을 합치지 않음. 수동 금융 항목과 수동 비움 보존.
- 클릭 시 먼저 준비 창을 열어 모바일 팝업 차단 방지. 상세 조회는 동시2개로 제한.
  중복 인쇄 준비 방지, 준비 상태 및 버튼 잠금/복구, 준비 창 닫힘 처리.
- 인쇄 조회에서 사진 선행 다운로드를 시작하지 않음. 상세 창·저장된 목록에 쓰지 않음.
- 최신 상세 조회 실패/원본 매칭 실패는 현재 목록 조건과 인쇄물 확인사항으로 명시.
  설명값 충돌·미제공 보증금/월 임대수입도 확인사항에 표시하며 가짜0원·수익률을 만들지 않음.
- 광고·관리 메모 보존. 메모가 없을 때 같은 원본 상세설명으로 보완. HTML은 문자로 인쇄.
- 상가임대만 선택한 인쇄는 기존 동기 표 형식 유지. 혼합 선택의 순서와 모든 매물 보존.
