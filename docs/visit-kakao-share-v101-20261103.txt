2026-11-03 임장완료 메모 및 카카오톡 채팅방 공유 v101

사용자 결정
- 선택한 매물에서 임장완료를 누를 때 정해진 형식으로 문구 작성.
  예: 괴정동 1-37 일반상가 1층 상가 11평 월2000에55 출입기준
- 나와의 채팅 자동발송이 아니라 보낼 채팅방을 직접 선택.
- 마지막 '출입기준'은 고정. 매물 지번과 카드 정보만 사용하며 GPS 불필요.
- 현위치 버튼 속도(v100)와 서로 다른 기능임을 명확히 안내.

구현
- 임장완료 저장 성공 후 카톡 메모 미리보기. 문구 복사 / 카카오톡 공유 / 닫기.
  실제 persisted=true이고 queued가 아닌 결과만 공유 미리보기를 연다.
- 주소에서 대전/대전광역시 및 해당 구 접두어만 줄이고 건물명·층/호실·유형·평수·조건 연결.
  상가점포/일반상가 유형은 '상가', 보증금·월세는 '월2000에55' 형태.
  목록의 표시 조건이 대표 원장과 다른 경우 선택된 표시 카드 조건을 캡처해 사용.
  미확인 값은 미확인으로 유지, 면적을 추측하거나 제곱미터/평 재변환하지 않는다.
  매매는 월세로 오인하지 않도록 '매매…만원'으로 구분.
- 기존 임장가자/공실박스 태그에 한정했던 완료 대상을 사용자가 체크한 매물로 확대.
  명시적 계약완료 상태만 제외한다. 원본광고 미노출을 실제 계약으로 추정하지 않는다.
  기존 메모는 보존하고 확인매물 표식만 기존 함수로 처리한다. 거래상태 변경 없음.
- 임장 저장과 공유 UI 실패 분리. 공유창 오류가 D1 저장 성공을 로컬에서 되돌리지 않는다.
  몇 개 매물의 완료 후 전체 목록을 다시 받던 작업은 v99 scoped 경로로 연결(최대51개).
  이전 초기 IDB 캐시 무효화 유지. 여러 건 대량/구버전 경로는 기존 전체 갱신 fallback.
- 휴대폰 세로 선택바에 임장완료도 표시해 병합/선택해제와 함께 접근 가능.
- Kakao SDK2.8.4는 공유 미리보기를 실제 열 때만 로드. 초기 지도/목록 진입 시 SDK 요청 없음.
  버전 고정 및 실제 공식 CDN 파일의 SHA384 SRI 검증. 기존 공개 지도 JavaScript 키 재사용.
  OAuth/로그인 토큰 저장·개인 연락처/사진·GPS·주소 검색 API 사용 없음.
- 사용자 클릭에서 sendDefault(text)를 동기 호출하여 카카오 공유 대상 선택 흐름으로 전달.
  방 고르기/최종 전송은 사용자가 카카오톡에서 수행. 팝업 호출을 전송 성공으로 표시하지 않음.
  공식 텍스트 템플릿200자 한도 초과 시 잘라 보내지 않고 전체 문구 복사를 제공.
  SDK 불가/지연/클립보드 제한 시 복사 또는 직접 선택 복사를 안내.
- CSP form-action은 sharer.kakao.com과 로그인 리다이렉트 accounts.kakao.com만 추가.
  native 공유용 frame-src에 kakaolink: 추가. 기존 나머지 보안정책 유지.
