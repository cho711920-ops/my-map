수정
- 매매 상세 메뉴의 항목 위치는 레이아웃이 바뀔 때만 계산·보관. 스크롤 프레임에는 숫자 비교와 실제 활성 항목 전환만 수행.
- ResizeObserver로 상세/본문 주요 그룹/항목의 크기 변경을 감지. 공적자료 지연 도착, 설명 펼침, 이미지 로딩, 화면 크기 변경 때 위치 갱신. 기존 명시적 _saleDossierSyncV3 호출도 유지.
- 메뉴는 기존처럼 스크롤 본문 밖 고정 위치. 새 상세/임대 전환 때 관찰자·이벤트·예약프레임 정리. 스크롤 중 상세 전체 재생성이나 강제 위치 이동 추가 없음.
- 그래프 포인터 처리는 프레임당 마지막 좌표만 처리. 같은 연도·같은 폭·같은 표시상태의 정보창/캡션/점 반경을 다시 쓰지 않음. 변경한 두 점만 갱신, 레이아웃 읽기는 DOM쓰기 전에 수행.
- 모바일 세로 스와이프 중 pointermove로 정보창을 갱신하지 않음. 탭·키보드 시점 조회, 기간/단위 변경은 유지. leave/cancel/교체 뒤 예약 포인터 작업 무시.
