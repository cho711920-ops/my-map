# 2026-09-28 찜폴더 지도 보기에서 개별 찜 제거

## 적용 범위

- 찜폴더의 **지도 보기**로 특정 폴더 필터가 활성화된 메인 매물 목록에만 적용한다.
- 각 매물 카드의 기존 선택 체크박스 **뒤에** `찜 제거` 버튼을 표시한다. 체크박스는 임장완료 등 기존 선택 작업에 사용한다.
- 현재 폴더명과 매물 주소를 보여주는 확인창에서 확인한 경우에만 그 폴더의 참조를 제거한다.
- 매물 원본, 다른 폴더의 같은 매물, 기존 찜 관리창의 제거 방식은 유지한다.
- 일반 목록·전체 찜 필터·고객매칭 카드의 체크박스는 유지한다. 특정 폴더 지도 보기에서도 전체선택과 선택 작업 표시줄을 기존 방식대로 사용할 수 있다.
- 이번 변경에는 이전에 논의한 스마트폰 지도/목록 통합 디자인이나 폴드 기기 판별 변경을 포함하지 않는다.

## 상태와 안전성

- 렌더링 당시 폴더 ID를 버튼에 연결하고, 확인 전후에 활성 폴더·로그인 계정·매물 소속을 다시 확인한다. 이전 폴더의 오래된 버튼으로 다른 폴더를 수정하지 않는다.
- 같은 주소·층이라도 대표매물 ID로 구분한다. 기존 키 형식도 기존 참조 해석을 통해 지원한다.
- 저장소의 내부 객체를 직접 수정하지 않고 새 스냅샷을 저장한다. 저장이 거절되면 기존 폴더를 유지한다.
- 기존 계정별 저장/클라우드 동기화 경로를 사용한다. 원본매물 삭제 API는 호출하지 않는다.
- 마지막 매물을 제거해도 현재의 빈 폴더 필터를 유지하며 목록 건수를 0으로 갱신한다.
- 지도에 고정해 둔 클러스터와 복귀용 선택 스냅샷에서 제거된 항목을 제외한다. 상세창이나 원본 링크에서 돌아와도 제거한 매물이 되살아나지 않는다.
- 연속 검토 중에는 살아 있는 인접 카드와 가상 스크롤 구간을 보존한다.
- 현재 상세창의 매물을 제거한 경우에만 상세창과 연결 선택을 정리한다. 취소·저장 실패·다른 매물 제거 시에는 기존 상세창을 유지한다.

## 검증

- `tests/favorite-map-removal.test.cjs`: 확인·취소, 폴더/계정 전환, 잘못된 참조, 저장 실패, 다른 폴더/원본 보존, 상세창 정리.
- `tests/favorite-map-pin-filter.test.cjs`: 클러스터 고정 선택 및 원본 링크 복귀 시 제거 항목 복원 방지, 일반 지도 무변경.
- `tests/browser/favorite-map-removal.spec.mjs`: 실제 UI 모듈을 사용한 PC/스마트폰 브라우저 확인·취소, 빈 폴더, 필터 해제, 원본 복귀, 긴 목록 스크롤, 상세 검토 후 제거.
- 전체 Node 회귀 검사, ESLint, 타입 검사, 기존 검색/찜/상세 브라우저 검사, Cloudflare 빌드와 배포 dry-run을 수행한다.
- 브라우저 검사는 루프백 가상 매물과 SDK 경계 대체를 사용한다. 운영 계정의 찜을 실제로 삭제하지 않으며, 실제 지도 SDK는 선택 처리 단위 검사와 구분한다.
- 사용자 승인 후 운영 배포하고 변경된 공개 자산이 로컬 빌드와 일치하는지 확인한다. 운영 DB 마이그레이션·수집기 설정 변경은 없다.

- 전체 Node 검사 925개 통과, ESLint·타입 검사·Cloudflare 빌드 및 배포 dry-run 통과.
- 새 기능 브라우저 검사 15개 통과. 스마트폰에서 목록을 가리는 상세창을 연 채 뒤쪽 버튼을 누르는 데스크톱 전용 시나리오 1개는 의도적으로 제외했다.
- 기존 검색·찜·상세 및 스마트폰 흐름 브라우저 검사 18개 통과, 기기별 해당하지 않는 시나리오 10개 제외.
- 사용자 배포 승인: `검수 후 바로 배포`.

### 체크박스 복원 후속 수정

- 최초 배포의 체크박스 대체 방식 때문에 임장완료를 위한 선택이 불가능하다는 사용자 피드백을 반영한다.
- 체크박스를 `찜 제거` 앞에 복원하고, 이 모드에서만 전체선택과 선택 작업 표시줄을 숨기던 CSS를 제거한다.
- 찜 제거 확인창·현재 폴더만 제거·다른 폴더 및 원본 보존은 그대로 유지한다.
- 후속 검수: 전체 Node 925개와 ESLint·타입 검사·Cloudflare dry-run 통과. 브라우저 16개 통과, 데스크톱 전용 시나리오의 모바일 실행 2개 제외.
- 브라우저에서 체크박스 위치, 전체선택/해제, 찜 제거 취소 시 선택 유지, 실제 임장완료 UI와 합성 저장 응답 후 확인매물 표시·선택 해제·찜폴더 보존을 검증했다. 운영 매물 상태는 테스트로 변경하지 않았다.
