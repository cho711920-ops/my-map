원인과 적용

- 건물매매 선택 시 건물매매 검토목록: 매매가를 크게 표시하고 광고 대지/연/전용/건축면적, 보증금 합계, 월 임대수입, 보증금 차감 단순 연 수익률, 광고 융자/실투자금, 건물용도/사용승인일/확인된 층·호실을 구분한다. 제공된 필드만 사용하며 빈 값을 0으로 채우지 않는다.
- 이자 차감 월수익·기준 미확인 월수익·광고 연 수익률은 별도 명칭으로 출력하며 월 임대수입이나 웹 계산 수익률로 바꾸지 않는다. 계산식과 미반영 비용을 하단에 명시한다.
- 토지매매 선택 시 토지매매 검토목록: 광고 토지면적, 그 면적을 분모로 한 평당가, 지목/용도지역/도로접면/형상. 토지에 층수·임대수입·건물 수익률을 넣지 않는다.
- 임대만 선택하면 기존 임장리스트 표를 유지한다. 혼합 선택은 모든 선택 항목과 순서를 유지하면서 각 카드의 거래유형에 맞게 출력한다. 현재 모드를 전체 선택 항목에 일괄 적용하지 않는다.
- 화면에 표시 중인 선택 원본 조건을 안정된 매물 ID로 대조해 인쇄에 사용하며 다른 원본의 매매가와 수입을 섞지 않는다. 화면 밖 선택은 기존 대표값을 사용한다. 추가 조회·자료 변경 없음.
- 매매는 A4 세로 전폭 카드로 바꾸고 긴 광고/관리 메모를 전체 너비에 배치했다. 메모를 잘라내거나 임의 요약하지 않는다. 출력일만 머리말에 표시하며 수집일을 등록일로 표시하지 않는다.
- 연락처의 소유자·임차인 명칭을 구분한다. 저장된 연락처가 없으면 없음을 표시하며 새 연락처를 추정하지 않는다.
- 인쇄창은 메인 화면에서 이미 로드된 현재 print-v2 CSS 규칙을 사용한다. 별도 빈 창의 스타일 요청에 걸려 출력이 진행되지 않거나 오래된 스타일을 참조하는 것을 방지한다. 규칙 접근 불가 시 현재 스타일 URL로 대체한다. 임대 표 데이터와 양식은 동일하다.
