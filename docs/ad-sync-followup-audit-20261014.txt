폐기된 이전 해석 (아래 내용으로 배포하지 않음)
- 사용자가 '운영현황의 과거 광고 집계를 빼고 지도에 표시되는 거래완료 후보와 숫자를 맞춰 달라'고 요청했다.
- 과거 원본 광고를 삭제하지 않고, 후보의 단위를 통합매물로 변경한다.
- 후보: 연결 원본이 하나 이상 있으나 활성 원본이 하나도 없는 통합매물. 직접 계약완료는 후보 집계에서 제외한다.
- 계약완료만 보기: 위 후보와 직접 계약완료의 합집합. 활성 원본이 남은 혼합 매물은 제외한다.
- 운영화면은 전체 광고 수 53,221 대신 현재 지도·거래시장·검색조건에서의 후보 수를 사용한다.
  후보 수와 직접 완료 수, 완료만 보기 합계를 구분하여 표시한다.
- 현재 지도 자료가 준비되지 않은 때만 서버 전체 공개 매물 집계를 쓰고 범위 차이를 명시한다.
- 현재 지도 자료가 준비됐을 때 후보 목록도 같은 로컬 집계를 사용하여 추가 조회를 만들지 않는다.
- 후보 목록은 50개씩 페이지 처리하여 수천 건 DOM을 한꺼번에 만들지 않는다.
- 이번 변경으로 과거 광고의 실제 플랫폼 종료 사실이 검증됐다고 설명하지 않는다.
