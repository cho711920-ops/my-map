건물 전용 카드·매매 정렬·비교 개선 — 2026-10-18 KST

요청과 범위
- 사용자가 건물·토지매매 추가 보완 제안에 '처리해줘' 승인.
- 직전 우선 추천 3가지: 건물 전용 카드 / 매매 전용 정렬 / 기존 비교표 진입·차이 강조.
- 상가임대는 기존 카드와 최근등록순 메뉴 유지. 토지의 기존 전용 카드와 필지조회 유지.
- 별도 법규 데이터 수집·가격변동 추적·규제 판단 기능은 이번 범위에 추가하지 않음.

1. 건물 전용 목록 카드
- 토지와 마찬가지로 매매 전용 DOM을 사용하며 건물은 네이비 계열.
- 유형·광고 제목·주소 / 매매가와 수익률 / 전용·대지·연면적·건축(건평) / 보증금·월 임대수입·용도 구획.
- 수집값이 있는 면적만 기존 배지로 표시. 층수·호실·매매범위 추정 배지 재도입 없음.
- 광고 면적과 건물 총매매가가 있을 때 대지 기준/연면적 기준 단가(만원/평) 추가.
  이 지표는 건물 총매매가를 해당 광고 면적으로 나눈 값이며 토지만의 가격이 아님.
- 사진/원본 광고 수/연락처 보유 색상/찜/수정/메모와 기존 건축물대장 콜백 유지.
- 사용승인 연도·엘리베이터는 기존 캐시 표시를 사용. 카드별 외부 정보 새 조회 없음.
- 모바일에서도 작업 버튼과 매매 비교용 체크박스 표시. 상가임대의 체크박스/행동 표시 방식 유지.

2. 시장별 정렬
- 공통: 최근등록순, 매매가 낮은/높은순, 대지·토지 넓은/작은순.
- 건물: 연면적 넓은순, 단순 수익률 높은순, 월 임대수입 높은순.
- 토지: 토지 평당가 낮은/높은순. 건물용 수익률/임대수입/연면적 항목은 표시하지 않음.
- 면적·가격 0/음수/미제공은 정렬값 없음. 실제 제공 월수입0·수익률0은 유효한 값.
- 값이 없는 매물은 양방향 모두 마지막, 동점은 기존 자연 주소 순서. 자료를 0으로 채우지 않음.
- 현재 필터에 맞는 원본에서 산출. 필요한 정렬값은 매물당 1회 미리 계산해 Map에 저장.
- 시장 전환 시 기존 동작대로 최근등록순 복귀. 임대 메뉴는 원래 HTML로 복원.

3. 비교 후보와 비교표
- 기존 매물 선택키를 그대로 사용해 매매 모드에서만 이름·가격·해제 버튼의 비교 후보 바 표시.
- 후보는 최대4개만 그리며 개수는 전체 표시. 같은 시장 2~4개일 때 비교표 버튼 활성.
- 스마트폰은 하단 탭 위에 배치하고 목록 하단 여백 확보. 별도 비교 목록 DB/자동저장 없음.
- 필터/목록 변경에 따른 선택 해제는 기존 정책 유지. 상가임대 복귀 시 바와 전용 여백 제거.
- 기존 비교표에 서로 다른 조건의 행 배경과 '조건 차이' 표시, 같은 항목 접기 체크박스 추가.
- 건물 비교에는 대지 기준/연면적 기준 단가 추가. 인쇄와 매물 열기 기존 기능 유지.
- 숫자 크기에 따라 좋은 매물/추천 매물로 단정하지 않음. 미제공 정보는 미확인.
- 비교표와 후보 가격은 현재 필터에서 표시한 원본을 우선해 master의 다른 원본 가격과 혼합 방지.
- 후보 바 갱신은 Set/Map으로 처리해 전체선택 시 매물마다 전체 목록을 재검색하지 않음.
