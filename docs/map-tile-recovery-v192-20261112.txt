## 2026-11-12 v192 지도 배경 타일 복구

- 지도 IMG 실패 신호만 기다리던 v105가 화면 밖에서 실패한 뒤 붙은 타일과 load/error 없이 멈춘 요청을 놓치는 경로를 보완했다. 구/동 흰색 집계와는 별개이며 클러스터/목록/사진/저장·수집 원장은 변경하지 않는다.
- 지도 내부의 허용된 카카오 CDN 타일만 관찰한다. 추가/원본 src 변경 시 미완료 타일을 등록하고 정상 load 후 즉시 해제한다. 정상 타일 재요청·전체 지도 재생성/강제 relayout/레이어 opacity 조작/상시 폴링은 없다. 짧은 dragend에 idle이 없거나 페이지 복귀한 경우도 재개한다.
- 실패 타일은 원래 URL로 재시도한다. 오류도 응답도 없는 10초 이상 요청만 기존 요청 합류를 피하는 제한된 query를 붙인다. CDN·타일 경로·기존 query는 보존한다. 이미지 노드·SDK load 리스너 유지, 타일당 최대 2회/한 번에 4개/80ms/분당 32회/기록 128개·2분 제한을 유지한다. 정상 통신 지연에 무분별한 재요청을 추가하지 않는다.
- 공식 tileAnimation:false로 불필요한 타일 페이드 효과를 제거하고 실제 타일 CDN 연결을 미리 준비한다. 이미지를 강제로 보이게 하거나 오래된 다른 좌표 지도를 대신 표시하지 않는다.
- tests/browser/map-tile-recovery-v105.spec.mjs를 test:principles에 포함했다. 실패 누락·초기 무응답·재시도 무응답·동작 취소·정상 느린 응답·부분/전체 실패·재시도 제한을 PC/휴대폰에서 검증한다. 기존 지연 상한/13개 skip은 변경하지 않는다.
- 실제 공개 SDK/CSP+가상 원장에서 타일 한 개를 지연시켜 실제 재수신/SDK tilesloaded/이미지 256px decode 및 화면 복구를 확인했다. 변경 전에도 나머지 타일의 화면 점유율은 98%였으므로 타일 한 개가 항상 전체 지도를 숨기는 원인이라고 단정하지 않는다. 사용자의 당시 통신/GPU 기록은 없으며 지속적 통신 단절의 무대기 보장은 하지 않는다.
- 변경 전 source a0b8cd2a/공개 683c9edc, outputs/v192-before-source.zip. 비공개 query와 고정 원버튼은 유지한다. 자세한 결과는 docs/map-tile-recovery-v192-20261112.txt 참조.
