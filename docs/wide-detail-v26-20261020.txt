변경
- wide-detail-v26.js/css를 추가하고 기존 통합 상세에 마운트/배치 훅을 연결했다.
- 충분한 공간에서는 큰 사진 왼쪽, 선택한 원본의 핵심 조건 오른쪽인 가로 카드.
- 최대1060px, 사용 가능한 카드 폭760px 이상일 때 좌우 배치.
  목록을 가리지 않도록 공간 부족 시 사진과 정보를 세로로 쌓는다.
- 사진은 가로폭 전체, 높이는 실제 이미지 비율. cover·고정 높이·최대 높이를 사용하지 않는다.
  긴 세로사진은 상세 내부에서 스크롤. 기존 원본 크게 보기·넘김·스와이프·재시도 유지.
- 카드 자체는 위로12px+페이드 약0.22초, 사진 크기를 확대/축소하지 않는다.
  동작 줄이기 설정에서는 이동·전환을 끈다. 모서리12px/얇은 선/은은한 그림자.
- PC 바로가기 네 개는 하단 고정. 선형 SVG와 글자, 기존 클릭 핸들러·매물ID 유지.
  휴대폰의 기존 전화·길찾기·찜·원본 하단 기능 및 관리 UI 제외 정책은 유지한다.
- 임대 조건은 보증금·월세·광고 면적·층/호실·관리비·권리금으로 구분.
  원본 presence=false/빈 값과 실제0원을 구분한다. 임대광고·수집값을 수정하지 않는다.
- 매매 요약·면적·공적자료·계산·사진·원문은 이미 생성된 실제 DOM을 옮겨 사용.
  계산 기준·선택 원본·사진 URL·운영 데이터 구조를 바꾸거나 새 API를 호출하지 않는다.
- 합치기/분리 등 기존 버튼은 광고 관리 펼침 안에 보존.
- 찜폴더 내 상세는 호스트 폭에 맞춰 세로로 배치하며 지도 상세로 복귀 가능.
- 검색창/목록/클러스터/지도 SDK/수집기/서버 로직/DB/찜 저장은 변경하지 않았다.
