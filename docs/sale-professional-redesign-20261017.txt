- 데이터가 없는 항목은 요약을 늘어놓지 않음. 미제공 수입을 0으로 만들지 않음.

2. 매매 상세
- 선택한 원본의 가격·주요 지표를 요약 패널로 표시. 건물은 네이비, 토지는 차분한 그린.

- 기존 융자·광고 실투자금·기재 수익률·설명 충돌 경고·원문·지적공부 면적 차이 경고를 보존.
- 제공된 가구 수 추가 표시. 긴 확인사항은 표 전체 폭으로 표시. 금액은 천 단위 구분.
- 사진 없는 경우에만 빈 사진 영역을 100px로 줄임. 사진 보기/전환/불러오기 로직은 유지.
- 이전 결정에 따라 건물매매 층·호실·매매범위 배지를 되살리지 않음. 원문은 그대로 열람 가능.
- 스마트폰에서도 기존 외부 필지 조회와 내 계정 매매 검토 도구를 사용 가능.

3. 검토·비교
- 건물: 기존 현금흐름 계산을 실투입·월/연 현금흐름·가정 연 수익률로 보기 쉽게 표시.

- 복수 필지 면적 합계·지번 입력·개인 검토 메모·계정 분리·버전 충돌 방어 유지.
- 기존 토지 검토에 숨겨진 임대 관련 가정값이 있어도 저장 시 보존.
