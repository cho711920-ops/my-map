요청과 적용 방식
- 임대조건 수정창의 임대인 전화번호 입력칸 오른쪽 안쪽에 건물공통 버튼을 배치했다.
- 번호 입력 후 한 번 누르면 별도 매물/지번 선택창 없이 해당 정확한 지번의 공통번호 규칙을 계정에 저장한다. 자동 지번 연결을 활성화해 현재 매물과 앞으로 들어오는 네이버·당근·공실박스 광고에도 표시한다.
- 지도에서 여러 지번을 같은 건물로 묶었더라도 이 동작은 현재 매물의 한 지번만 대상으로 한다. 기존 공통번호가 있으면 공통 설정으로 변경·해제·개별번호 예외 관리를 유지한다.
- 공실박스의 수집 번호 자체를 수동 수정 번호로 오판하지 않는다. landlord_phone 수동 변경 표시는 계속 우선하며, 이후 별도 지정한 개별번호는 보존한다.
- 원본 번호 열, 광고, 메모, 월세, 지도 묶음을 일괄 덮어쓰지 않는다. 공통 설정은 독립 저장하고 일반 조건 저장에는 입력 중인 월세/메모만 종전 방식대로 적용한다.
