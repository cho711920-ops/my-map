사용자 승인
- 직전 제안 1번: 매매 수정창 금액 입력 아래 한글 환산 표시.
- 이어 건물매매·토지매매를 전문 사이트 느낌으로 디자인 보완.
- 앞으로도 신규 기능을 늘리기보다 디자인 완성도에 우선순위를 둔다.
- 상가임대 영향 금지. 수정 후 변경점과 검수·운영 반영 여부 브리핑.

적용
1. 만원 단위 입력의 실시간 보조 표시
   80000 → 8억원, 99500 → 9억 9,500만원, 0.5 → 5,000원.
   매매가와 건물 임대보증금·월 임대수입·융자금·실투자금·광고 월수익에 적용.
   빈 입력·0원·잘못된 금액 구분, 입력에 설명 연결 및 상태 알림 제공.
   저장 단위/숫자/원본 광고는 변경하지 않으며 입력만으로 저장 요청하지 않는다.
2. 매매 카드
   남색 가격 / 중립 회색 보조정보로 통일, 카드 테두리·그림자·배지 장식 완화.
   사진·매물명·주소·가격·면적 및 임대 현황의 글자와 간격 정돈.
   모바일 토지 카드의 공유 grid 높이 때문에 생기던 빈 공간 제거.
   링크 버튼의 불필요한 가로 늘어남 제거, 모바일 버튼 높이 36px 유지.
3. 상세·수정·검토창
   짙은 유색 요약 배경을 밝은 보고서형 표면으로 통일하고 제목/값 대비 확보.
   상세 내비게이션·정보표·입력 테두리·버튼 우선순위·키보드 초점 정리.
   사진 contain/안정된 갤러리 높이, 전화 유무/찜/거래완료 검토 상태는 유지.
