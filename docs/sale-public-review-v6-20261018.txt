아래의 미연계/미확인 문구는 v6 최초 배포 당시 기록임.

사용자 승인
- 직전 건물 제원 / 토지 이용규제·공시지가 / 주변 유사 실거래 제안에 '수정 ㄱ ㄱ'.
- 상가임대 영향 금지. Dot 컴퓨터 연결은 사용자가 내일 직접 진행하므로 재시도하지 않음.

적용
1. 건물 제원
- 매매 상세에 주용도·구조·승인일·면적·건폐율·용적률·주차·승강기 조건표.
- 기존 건축물대장 요약 API와 캐시 재사용. 버튼 클릭 때만 정확한 지번 확인과 조회.
- propertyId를 비워 호출해 listings의 건물정보/주소를 저장·갱신하지 않음.
- 여러 건물·동이면 사용자가 선택. 첫 번째 행을 전체 건물로 임의 확정하거나 합산하지 않음.
- 주차는 자주식·기계식, 실내·실외가 모두 제공될 때만 총대수 합산. 결측을 0으로 보충하지 않음.
- 광고 용도·승인일과 대장 정보를 병렬로 대조. 광고 원문이나 기존 면적·수익 계산을 덮어쓰지 않음.
- 선택한 건물 기준 면적이며 일부 지분·집합 전유면적과 다를 수 있음을 표시. 원문 출처와 조회일 표시.

2. 토지 필지·공적자료
- 수집 광고의 지목·용도지역·추가 지역·도로접면·형상·면적을 광고 기재값으로 구분.
- 정확히 확인된 한 필지의 토지이음(이용계획·공시지가·확인도면), 밸류맵 링크 제공.
- 주소가 도로명·여러 필지·비공개이면 조회용 지번을 입력·적용할 수 있음. 매물 주소/좌표 저장 없음.
- 규제 원문·공시지가를 웹 내부에 자동 표시하는 연계는 미완료.
  현재 배포 환경의 secret 이름 목록에 VWorld 등 해당 연계 인증키가 없고, 별도 제공기관 연계가 필요.
  화면에 '아직 자동 연계되지 않았습니다'를 표시하며, 미조회를 규제 없음·조회 완료로 표시하지 않음.

3. 실거래 참고
- 인증된 GET action=saleTransactions. 토지 / 상업·업무용 건물, 시군구·계약월별 공식 XML API 연결 구현.
- 기존 DATA_GO_KR_SERVICE_KEY 또는 별도 MOLIT_TRADE_SERVICE_KEY를 사용. 키를 브라우저나 로그에 노출하지 않음.
- 버튼을 누를 때 조회하고 동일 법정동에서 계약월·대지/거래면적0.5~2배·같은 지목/용도지역 필터 적용.
- 건물은 기본 일반건축물만. 상업·업무용 데이터의 범위를 표시하며 주택/공장/창고가 포함됐다고 주장하지 않음.
- 호가와 실거래를 분리. 해제일/해제표기/지분표기 제외. 부분 공개 주소를 동일 매물 이력·정확한 거리로 단정하지 않음.
- 페이지/총건수 검증, 최대4페이지(각1000행). 미완료는 일부 자료로 표시하고 완전한 0건으로 단정하지 않음.
- 완전히 확인된 구·월 공개자료만 R2 6시간 캐시. 조회 중복은 병합. 광고/거래상태/운영 매물 DB 변경 없음.
- 이용 승인 부족·제공기관 장애·정상0건을 분리. 국토부 공식 실거래 사이트 연결 유지.
- 운영 인증키에 두 API의 활용신청 권한이 있는지는 이 턴에서 실제 인증 호출로 검증하지 못함.
  API 연결 코드와 모의 응답 검증을 실제 운영 실거래 조회 성공으로 보고하지 말 것.
