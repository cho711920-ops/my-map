1. PC 목록 상세형/간결형
- 매매 목록 위에 전환 버튼. 시장별 현재 창 메모리에만 유지하며 검색조건 저장 기능은 추가하지 않음.
- 건물: 대지·연면적·월 임대수입·단순 연 수익률. 토지: 면적·광고면적 기준 단가·지목·용도지역.
- 0원 수입은0으로, 미제공은 미제공/산정불가. 공부면적으로 광고 단가를 다시 계산하지 않음.
- 사진 없는 칸은 간결형에서 숨김. 전화 보유 색상·사진/상세 진입·찜·비교 체크·메모·출처/등록일 유지.
- 토글은 sticky로 접근 가능. 밀도 변경 시 가상목록 높이 추정 캐시를 비우고 첫 표시 매물의 화면 위치를 보존.
- 스마트폰은 기존 상세형 카드. 추가 매물/외부 API 조회 없음.

2. 상세 탐색 메뉴
- 최대5개: 요약 / 토지·건물 / 공적자료 / 매입검토 / 사진·원문.
- 기존 정보표·건물제원/토지공적자료·실거래·계산기·사진/원문은 유지. 그룹 안 실제 위치에 따라 활성 표시.
- 사진·원문은 원문을 펼친 뒤 이동. 가려진 빈 사진은 대상에서 제외. 임대에서는 매매 탐색 제거.

3. 광고·공적자료 차이 요약

- 단순 표기 차이를 오류·허위 광고라고 단정하지 않으며 지분·복수 필지·매매범위 확인 안내.
- 여러 건물은 직접 선택한 건물만 대조. 미제공/다른 조회 지번/이전 상세의 늦은 응답은 비교하지 않음.
- 주소 적용·재조회 시작·동 선택 해제 시 이전 대조 자료를 지워 검토서에 오래된 다른 자료가 섞이지 않게 함.

4. 건물 수익 시나리오
- 기존 계산기 아래 현재 가정 / 금리 상승 / 공실 증가를 표시.

- 월 현금흐름·연 수익률, 음수도 그대로 표시. 합산 비율100% 초과·입력 누락은 계산하지 않음.
- 상승폭은 현재 창의 비교용. 기존 저장 가정·광고 가격/수익률을 바꾸지 않음. 기존 기본 입력/명시적 저장 흐름 유지.
- 원금상환·소득세·양도세 미반영 등 기존 가정 안내 유지. 수익·가격·개발가능성 추천 자동판정 없음.
