# 2026-09-22 스마트폰 세로 전용 화면

## 변경 범위

스마트폰으로 확인된 기기에만 `js-phone-app-v2`를 적용한다. 화면 폭만으로 판단하지 않고 기기 정보, 터치 입력, 실제 화면 크기를 함께 확인한다. iPad·Android 태블릿, 태블릿 분할 화면, 폭을 좁힌 PC는 기존 화면을 유지한다.

| 기존 스마트폰 | 변경 후 |
| --- | --- |
| 로고·빠른등록 및 지도/매물/임장/고객/더보기 메뉴 | 상단 검색창과 지도/매물/찜 3개 메뉴 |
| 여러 목록 필터가 상시 노출 | 목록에는 건수·정렬, 나머지는 상세 필터에 배치 |
| 목록에서 전화·내비 등 여러 버튼 노출 | 가격 중심 목록과 찜 버튼, 상세 하단 전화·길찾기·찜·원본 |
| 공통 찜 관리 창 | 폴더 목록 → 폴더 매물 → 상세 화면, 뒤로 가기와 탐색 위치 유지 |
| 작은 화면에서도 가로 UI 사용 | 가로에서는 세로 사용 안내, 회전 후 검색·매물 상태 유지 |

필터 변경은 적용 버튼을 눌렀을 때 반영하며 닫기는 취소한다. 소프트 키보드로 화면 높이만 줄어들어도 회전 안내를 띄우지 않는다. 수집기, 자동수집 일정, 운영 DB 및 계정 데이터는 변경하지 않았다.
