적용
1. 매매 상세를 항목 탐색이 가능한 자료 패널로 재구성
- 고정 탐색 메뉴: 매매요약 / 토지정보 / 건물정보 / 면적 / 금액·수익 / 광고원문 / 사진.
  실제 정보가 있는 항목만 표시. 클릭 시 내부 스크롤 이동, 현재 항목 표시.
- 건물은 네이비 자산 요약과 임대금액, 토지는 그린 요약과 지목·용도지역·도로접면·형상을 배치.
- 상세 면적은 독립 지표, 조건은 좌측 라벨·우측 값의 행 단위 표로 구성.
- 자료가 없는 금액·필지항목은 접힌 확인 항목에만 모아 표시. 제공된 0과 미제공은 구분.
- 검토·외부 조회 도구를 요약 가까이 이동. 외부 정보는 기존 정확한 지번 확인을 거쳐 열람.
- 사진은 요약 아래로 이동하되 기존 gallery DOM·사진 전환/재시도/카운터를 보존.
  사진이 없고 사진 수도 0인 경우에만 빈 사진 영역을 생략.
- 임대 상세로 전환하면 매매 전용 탐색 메뉴·스크롤 핸들러를 정리. 임대 기존 구성 유지.

2. 매매 지도 전용 일반/위성/지적편집도
- 사용자가 누를 때 기존 카카오 SDK의 ROADMAP/HYBRID/USE_DISTRICT로 전환.
- 매물 좌표·군집·선택·필터·개수를 재계산하거나 운영 자료를 수정하지 않음.
- 매매 모드 간에는 선택 유지. 상가임대 복귀 시 이 기능이 올린 지적 레이어만 제거하고 기존 지도 종류 복원.
- 기본 시작은 기존 지도. 추가 지도 타일은 선택 시 요청하며 새 외부 데이터 API·서비스 계정을 추가하지 않음.
- 목록을 연 경우에도 전환 도구가 지도 영역 안에 위치하도록 배치.
- 지적편집도 활성 시 참고용이며 현행 지적·법적 경계와 다를 수 있다는 안내 표시.
  법적 필지 경계 확정·측량·토지이용계획 확인을 대신하지 않음.

3. 매입 검토와 비교 실무
- 광고 금액 다시 적용: 건물은 매매가·보증금·월 임대수입, 토지는 매매가만 적용.
  대출·이자율·공실·운영비·취득 부대비용 가정과 메모·필지는 유지. 자동 저장은 하지 않음.
- 기존 검토를 불러오는 동안 먼저 입력한 필드는 늦은 응답이 덮어쓰지 않음.
- 저장 요청 뒤 추가 편집이 있으면 전부 저장됐다고 표시하지 않고 미저장 변경사항을 알림.
- 비교표에 전용면적·건축면적을 보완하고 면적을 평/㎡로 병기.
- 비교표 인쇄 버튼과 전용 인쇄 스타일. 인쇄 시 앱 배경과 작업 버튼은 제외.
- 기존 계정 분리·expectedVersion·expectedAccountEmail·수집값/가정값 분리·원본 충돌 검사를 유지.
