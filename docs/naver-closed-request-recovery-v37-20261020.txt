변경
- 서버는 running saveNaverBatch의 정확한 소유 세션이 collector 소유 네이버이고 stale-session으로 abandoned된 증거, 시작/요청/종료 시각, 종료 뒤 갱신 없음, 요청120분·종료5분 경과를 모두 확인한다.
- 조건 충족 시 ok:false / naver_closed_session_rescan / requiresFreshManifest:true를 반환한다. 기존 요청 claim은 계속 running으로 예약해 동일 저장 재전송을 차단한다. 저장 성공을 만들어 내거나 만료/삭제하지 않는다. 실제 완료 결과가 있으면 기존 결과를 그대로 반환한다.
- 새 claim에는 소유 sessionId만 기록한다. 이전 claim은 정해진 S-NAVER 시각/난수 접두사로 정확히 소유 세션을 찾는다. 소유자/유형 불일치, 종료 증거 없음, 아직 실행 중인 요청은 기존처럼 대기한다.
- abandoned 네이버 세션으로 새 저장/manifest를 보내 세션을 다시 살리는 경로를 차단한다.
- 네이버6.0.12는 이 응답을 받으면 같은 요청의 pending descriptor와 그 소유 세션의 checkpoint만 해제하고 현재 시도를 끝낸다. 미완료 전체수집을 완료 처리하지 않는다. 다음 기존 재시도는 새 세션에서 최신 전체 manifest를 대조하고 이미 저장된 광고는 건너뛴다.
- 확장1.1.18은 새 네이버 클라이언트를 포함한다. 예약/대상/인증/당근 로직은 변경하지 않는다. 운영 DB 직접 SQL 수정/삭제 없음.
