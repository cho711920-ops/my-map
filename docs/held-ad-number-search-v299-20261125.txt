원인과 변경
- 5081592는 수집 원본에는 있으나 정확한 주소가 없어 원장/listing_sources 등록 전에 보류됐다. 기존 번호 검색은 등록 원본에만 적용돼 이 광고를 찾지 못했다.
- 광고 화면의 주소 숨김과 수집 응답의 주소 부재는 다르다. 실제 다른 원본 표본에는 연결 건물의 지번 정보가 남아 있었고, 5081592에는 공개 동 정보만 있었다. 공개 좌표를 역지오코딩해 정확한 지번으로 확정하지 않는다.
- authenticated D1 GET heldListingSearchV299는 숫자/출처/거래시장/최신 처리본을 확인한다. 기존·비활성·종료 원본의 재노출, 다른 시장/계정/광고의 늦은 응답을 차단한다. 주소 오류 원본의 허용 필드만 반환하며 location은 null, 연락처/비공개 주소/좌표/큐 본문을 노출하지 않는다.
- 명시적 원본번호 검색에서만 별도 원본 카드·사진·조건·원본 링크를 표시한다. 일반 지도·클러스터·기본 목록에 보류 자료를 대량 추가하지 않는다. 원장 체크/편집/병합을 부여하거나 DB에 원장을 생성하지 않는다.
- 자료 갱신 세대가 바뀌면 원본도 재조회한다. 기존 필터를 따르며 사진 다음 장은 실제 decode 후 전환한다.
- 작은 화면에서 실제 원본 카드가 있을 때만 기존 빈 결과 안내를 표시하지 않는다. 조회 중/오류/필터로 원본이 사라진 경우의 빈 결과 안내는 유지한다. CSS 인접 형제 선택자를 사용한다.
