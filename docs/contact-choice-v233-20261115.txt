요청 및 범위
- 임대인·사모·사장·관리 등 등록 연락처 중 하나를 클릭해 임대인 전화번호 칸에 넣고 기존 건물공통 버튼으로 지정한다.
- 번호 선택 자체는 현재 수정창의 초안만 바꾼다. 저장 또는 공통 버튼을 누르기 전 운영 매물·공통 설정·연락처 원문을 바꾸지 않는다.

동작
- 임대인측으로 표기된 임대인/주인/사모/사장/관리/가족 칩은 키보드·터치 가능한 버튼으로 표시하고 선택한 칩을 파란색으로 구분한다. 세입자·중개사·미분류 번호를 임대인으로 자동 지정하지 않는다.
- 칩 선택은 로컬 동기 처리이며 새 조회를 하지 않는다. 기존 번호를 덮어쓰는 선택은 사용자가 직접 누를 때만 하며, 이후 메모 수정/늦은 수집 연락처가 사용자의 선택을 되돌리지 않는다.
- 새 공통 등록은 기존 한 지번 원버튼/CAS 저장을 사용한다. 이미 공통번호가 있으면 기존 변경창에 선택 번호를 미리 넣고 적용 범위를 확인해 저장한다. 기존 다른 지번·개별번호 예외·신규 광고 연결 규칙을 임의 확대하지 않는다.
- 기존 공통번호와 다른 번호를 선택한 초안에는 적용 완료 초록색을 표시하지 않는다. ‘아직 공통 적용 전’으로 구분하며 일반 저장으로 선택 번호를 조용히 버리지 않는다. 공통 설정 저장을 먼저 안내한다.
- 계정·원장·편집 세션·저장 중/충돌 중 경계를 검증하며, 닫히거나 교체된 수정창의 옛 선택은 새 수정창에 적용하지 않는다.

- 수정창 열기/취소만으로 원장의 실제 상태를 다시 저장하지 않는다. 최신 값 비교의 상태 재선택과 초안 복구에도 같은 표시 규칙을 사용한다.
