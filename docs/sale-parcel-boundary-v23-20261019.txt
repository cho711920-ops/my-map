구현
- 토지 상세에서 사용 가능 여부를 확인한 뒤 경계 보기 버튼 제공.
- 클릭한 지번을 기존 정확 일치 해석기로 PNU까지 확인한 후 해당 필지만 조회.
- 브이월드 LP_PA_CBND_BUBUN, EPSG:4326, pnu:=:19자리 정확 필터. 고정 호스트만 조회.
- Polygon/MultiPolygon, 여러 구성면·내부 빈 공간 보존. 임의 사각형/원/근처 필지 대체 금지.
- 청록색 외곽선과 옅은 12% 채움, 필지 번호. 번호/필지표 클릭 시 해당 필지 강조.
- 저장된 개인 검토 필지표의 순서·주소·입력 면적을 읽어 최대30필지 함께 보기.
  필지표나 광고·좌표·호가·원본·찜에는 쓰지 않는다. 저장하지 않은 초안을 자동 저장하거나 닫지 않는다.
- 주소/경계 하나라도 실패하거나 중복 PNU이면 부분 성공을 전체로 표시하지 않고 해당 번호 안내.
- 지도 목록에서 광고/내 입력 면적과 필지 전체 경계의 차이를 명시.
- 공부 면적은 사용자가 별도 버튼을 눌렀을 때 기존 saleParcelFacts로 조회한다.
  같은 PNU·양수 면적을 검증하고 광고/입력 면적은 보존한다. 1㎡ 넘는 차이는 매매 범위 확인 안내.
- 경계 표시 성공 후 기존 상세를 닫고 모바일은 지도 탭으로 이동. 필터·선택·기존 매물은 유지.
- 경계 숨김, 새 상세 열기, 상세 닫기, 다른 시장 전환, 페이지 이탈 때 오버레이·대기 요청 정리.
- 서버: 로그인/계정 일치 경계 유지, 전용 키 서버 보관, 비공개 응답.
  최대512KiB/10초, redirects 미추적, 엄격한 PNU/응답 수/좌표계/한국 좌표 범위/폐곡선 검증.
  필지당 최대10,000점/전체 표시30,000점, 서버 동시4/브라우저 동시2, 동일 조회 합침.
