운영 오류 확인
- 사용자 운영현황 발급 실패 수정 요청. 실제 mutation_results의 saveLocalAccount 실패 기록 5개를 읽기 전용 확인.

수정
- PBKDF2-HMAC-SHA256/310000회/16바이트 임의 salt/32바이트 결과와 기존 저장 형식을 그대로 유지.
- 100000회를 초과하는 PBKDF2는 고정 의존성 @noble/hashes2.4.0의 pbkdf2Async 사용. 100000회 이하는 기존 WebCrypto 사용.
- 기존100000/310000/600000회 형식과 Node 표준 결과 동등성 확인. 새 계정/기존 비밀번호 검증 모두 같은 함수 경로 사용.
- 반복 횟수 하향/기존 사용자 암호화 데이터 재작성/사용자 비밀번호 추출·대신 설정 없음.
- 발급 중 ‘연결 중…’과 상태 안내, 중복 제출 차단, 실패 시 버튼 복원 및 재시도 지원.
- 계정 연결/권한/찜·메모·매물·임장 보존 및 v51/v52 기능 유지. 수집 작업 변경 없음.
