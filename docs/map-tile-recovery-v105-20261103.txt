2026-11-03 지도 이동 중 배경 타일 누락 복구 v105

증상 / 근거
- 사용자 화면: 매물 클러스터는 남고 배경 일부만 흰 사각형으로 비어 있음.
- 실제 카카오 SDK + 현재 공개 CSS/CSP를 사용한 격리 브라우저에서 타일 요청 3개를 일시 실패시켜 유사 경로 재현.
  실패 이미지 naturalWidth=0, opacity=0 상태로 남고 tilesloaded가 완료되지 않았다.
  이동/확대만으로 복구되지 않는 경우를 확인했다.
- 실패한 이미지의 원래 URL을 다시 지정하면 SDK의 기존 load 리스너가 정상 완료하고 빈 타일이 복구됨을 확인.
- 특정 사용자 PC의 당시 네트워크 실패 기록을 직접 읽은 것은 아니다. 모든 GPU/드라이버/지연 원인을 단정하지 않는다.

구현
- map-tile-recovery-v105.js를 지도 생성 전 로드하고 메인 지도에만 연결.
- 지도 내부에서 실제 실패한 IMG 중 알려진 카카오 배경 타일 호스트/경로만 취급.
  현재 mts.kakaocdn.net/api/v1/tile 및 기존 daumcdn 타일 경로 지원.
  매물 사진·로드뷰·지도 외부 이미지·지도 업체 로고는 제외.
- 기존 SDK의 이미지 노드/이벤트 리스너/타일 URL 유지. 같은 URL을 재지정하여 SDK가 직접 완료 처리.
  SDK opacity/변환값/DOM 레이어를 강제로 수정하지 않고 정상인 타일을 다시 받지 않는다.
- 실패 이미지 자체는 크기가 0일 수 있어 이미지 사각형으로 제외하지 않는다.
  SDK는 주변 버퍼 타일도 레이어 완료에 사용하므로 연결된 실패 버퍼도 복구.
- 타일 이미지·URL당 최대 2회(첫350ms, 두번째1200ms 대기), 한 번에4개/80ms 간격, 1분 구간 최대32회.
  기록 최대128개/2분 보관. 반복 오류 무한 재요청 방지.
- 드래그/확대 중 새 재시도 중지, idle 후 재개. 오프라인/숨겨진 탭/숨겨진 지도/pagehide 중 중지.
  온라인 복귀/표시/페이지 복귀 시 남은 예산 안에서 재개.
- 재사용된 이미지의 URL이 바뀌면 이전 타일 요청을 취소 대상으로 제거. 새 지도 연결 시 리스너·타이머 정리.
- 별도 목록 갱신, 지도 중심 이동/축척 변경, 강제 relayout, 새 GPS 요청, 지도 전체 재생성 없음.
  기존 idle 갱신/중복 범위 생략/카드 재사용/수집기 동작 유지.
- 보조 복구 모듈 초기화 오류도 기존 매물 로딩을 막지 않도록 부팅 경로 보호.
