  단순 '초기화면에서 안 보임'만으로 자동후보 확대하지 않는다. 기존 수집 유지/확대 보류.
- 광고자(중개사/당근 세입자) 정보 보강, 네이버 지도로 전환, 현 지도 장소검색 UI는 보류·논의 단계다.
  새 근거/승인 없으면 구현하지 않는다.
- 고객별 활용/타 서비스 비교는 제품 제안으로 할 수 있으나 필요없는 기능 증설/자동배포 권한은 아니다.

평일 자율 리뷰 예약
- 기존 automation id=js, heartbeat, 이름=JS부동산 평일 자율 운영·서비스 비교.
- 사용자는 평일11시KST 운영점검+매일 타서비스 비교 브리핑을 원한다. 안전한 읽기검수/기존테스트/제안만.
  광고완료·삭제·강제수집·배포/푸시·외부연락·비용은 예약만으로 실행하지 않는다.
- 새 채팅으로 target을 이전할 때 기존 이름/본문/상태/일정/알림선호를 보존하고 중복예약을 만들지 않는다.
- 인계 중 기존 js 예약의 target을 위 새 채팅으로 변경했고 로컬저장 target_thread_id까지 재확인했다.
  이름/본문/상태/rrule은 보존했고 중복예약은 생성하지 않았다.
- 인계시 로컬 저장 rrule은 11:15/주7일 형태여서 원래 평일11시 요청과 불일치가 있다.
  이번 인계에서는 일정은 바꾸지 않는다. 새 채팅에서 확인 필요 항목이며 '정확히11시평일'로 검증됐다고 하지 않는다.

검수·복구 실무
- 사용PC16GB 메모리부족 이력이 있다. Node --max-old-space-size=192, 테스트 동시1.
  전체Node와 브라우저 무거운 검수 동시실행 금지. 브라우저는 JS_BROWSER_CHANNEL=msedge, worker1.
- Wrangler명령은 직렬로 하여 OAuth refresh충돌 방지. 인증/개인정보를 출력하지 않는다.
- 최신 검수 산출물은 outputs/remove-list-status-full-20261015.log,
  outputs/remove-list-status-browser-20261015.log, outputs/remove-list-status-deployment-20261015.json.
- 전체Node: node --max-old-space-size=192 --test --test-concurrency=1 tests/*.test.mjs tests/*.test.cjs tools/test-*.cjs
- 관련browser: advertisement-presence.spec.mjs / today-listings.spec.mjs / list-thumbnail-recovery.spec.mjs.
- build: tools/build-cloudflare-assets.mjs. 배포 wrangler deploy, 사전 --dry-run.
  공개검증: outputs/today-new-fix-20261013/verify-deployment.mjs (두 도메인32개 읽기검증).
- css/style.css / index.html / js/map.js / js/script.js의 기존 혼합EOL을 전체정규화하지 않는다.
  outputs/format-today-line-endings.mjs 사용 금지. 필요한 경우 preserve-original-eols.mjs 내용을 먼저 확인.
- 롤백 전 최신수집/찜/메모 손실을 구분한다. 코드복원과 D1전체되감기는 다르다.
  외부private SQL백업/TimeTravel기록 위치는 기존 문서에서 확인하고 임의의 백업성공을 주장하지 않는다.
