# Edge 매일 자동수집

## 구조

- 기존 네이버·당근·공실박스 수집기는 실제 수집과 D1 반영을 담당한다.
- Edge 확장 프로그램은 자동수집 대상, 오전 6시 일정, 최근 실행 기록만 전용 Edge 프로필에 보관한다.
- Windows 작업 스케줄러는 30분마다 전용 Edge 프로필을 깨우고, Edge 설정에 저장된 시간이 지난 오늘의 첫 확인에서만 수집한다. PC가 꺼져 예약 시각을 놓쳐도 그날 다음 확인 때 한 번 실행한다.
- 대상은 네이버 → 당근 → 공실박스 순서로 실행한다. 한 대상이 실패해도 다음 대상은 계속 실행한다.
- 수집 API 키, 사이트 로그인 쿠키, 대상 목록은 사용자 PC의 전용 프로필 밖으로 내보내지 않는다.

## 설치

```powershell
powershell -ExecutionPolicy Bypass -File tools/install-edge-auto-collector.ps1 -Schedule 06:00
```

설치 후 자동으로 열리는 전용 Edge에서 필요한 사이트에 로그인한다. 각 사이트에서 통합 수집기를 실행하고 대상을 선택한 뒤 `자동수집 등록`을 누른다.

- 네이버: 구 클러스터를 선택하고 등록한다.
- 당근: 구 클러스터를 선택하고 등록한다.
- 공실박스: 저장할 지도 위치·확대·필터를 맞추고 화면 전체 숫자 클러스터를 한 번 클릭한 뒤 등록한다. 매일 저장된 화면에서 가장 큰 전체 클러스터를 다시 선택한다.

확장 프로그램 아이콘의 `JS 자동수집` 화면에서 `매일 자동수집 사용`을 켜고 시간을 저장한다. `지금 전체 실행`으로 예약 전에 시험할 수 있다.

## 안전 규칙

- 같은 사이트의 같은 원본 ID는 새 매물로 만들지 않는다.
- 변화가 없는 원본은 노출 확인 시각만 갱신한다.
- 가격·임대조건·사진·연락처가 달라졌을 때만 차등 반영한다.
- 부분수집, 주소 오류, 상세조회 실패는 미노출 횟수를 올리지 않는다.
- 사용자가 작성한 메모와 수동 계약완료 상태는 자동수집기가 변경하지 않는다.
- PC가 꺼진 동안 놓친 작업은 다음 로그인 후 가능한 경우 작업 스케줄러가 실행한다.

## 제거

```powershell
powershell -ExecutionPolicy Bypass -File tools/uninstall-edge-auto-collector.ps1
```

이 명령은 예약 작업만 제거하며 전용 Edge 로그인 프로필과 기록은 복구를 위해 남긴다.
