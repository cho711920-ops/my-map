# JS 네이버부동산 북마크 수집기 v3.5.0

확장 프로그램 없이 북마크 버튼 하나로 네이버페이 부동산의 선택 클러스터를 `JS부동산 매물현황` 시트에 저장합니다.

## 사용 순서

1. `네이버부동산_수집버튼_설치.html`을 엽니다.
2. `🟢 네이버 수집` 버튼을 북마크바로 끌어놓습니다.
3. 네이버페이 부동산 상가 지도에서 북마크 버튼을 누릅니다.
4. 숫자 클러스터를 누릅니다.
5. 수집창에서 `클러스터 전체 저장`을 누릅니다.

## 동작

- 현재 네이버 목록 요청을 감지합니다.
- 다음 페이지를 최대 500페이지까지 자동 조회합니다.
- 최대 범위에 도달했는데도 목록이 남으면 일부 저장을 막고 클러스터 분할을 안내합니다.
- 매물을 15개씩 Apps Script `saveNaverBatch`로 전송합니다.
- `매물ID`를 먼저 비교하고, 지번주소·층/호실·보증금·월세·평수가 모두 같은 기존 매물도 중복으로 제외합니다.
- 네이버 원본 상세페이지 주소를 시트1 Q열 `원본링크`에 함께 저장합니다.
- 수집 로직은 `my-map/js/naver-collector.js` 한 파일만 업데이트하면 집·사무실 PC에 동시에 반영됩니다.
