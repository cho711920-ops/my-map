# JS 네이버부동산 북마크 수집기 v4.1.3

확장 프로그램 없이 북마크 버튼 하나로 네이버페이 부동산의 선택 클러스터를 `JS부동산 매물현황` 시트에 저장합니다.

## 사용 순서

1. `네이버부동산_수집버튼_설치.html`을 엽니다.
2. `🟢 네이버 수집` 버튼을 북마크바로 끌어놓습니다.
3. 네이버페이 부동산 상가 지도에서 북마크 버튼을 누릅니다.
4. 숫자 클러스터를 누릅니다.
5. 수집창에서 `클러스터 전체 저장`을 누릅니다.

## 대전 전체 수집

1. 지도 상단 지역에서 `대전`과 아무 구(예: `서구`)를 선택하고 원하는 매물 필터를 고릅니다.
2. `현재 목록 다시 감지`를 누릅니다.
3. `대전 전체 이어서 수집`을 누릅니다.
4. 클러스터나 동을 누르지 않아도 동구·중구·서구·유성구·대덕구를 자동 순회합니다.
5. 구별 페이지를 즉시 저장하며, 중단되면 저장된 다음 페이지부터 이어집니다.
6. 주소 미확인 등 개별 실패 매물은 전체 수집을 멈추지 않고 보관한 뒤 마지막과 다음 실행 때 다시 시도합니다.
7. 네이버 5페이지·최대 100개를 한 번에 저장해 페이지별 저장 방식보다 서버 호출을 약 5분의 1로 줄입니다.
8. 중단되면 같은 버튼을 다시 눌러 남은 구역부터 이어서 처리합니다.

## 동작

- 현재 네이버 목록 요청을 감지합니다.
- 기존 선택 클러스터 수집과 대전 전체 수집을 함께 제공합니다.
- 다음 페이지를 최대 500페이지까지 자동 조회합니다.
- 최대 범위에 도달했는데도 목록이 남으면 일부 저장을 막고 클러스터 분할을 안내합니다.
- 매물을 서버의 안전 상한인 100개씩 Apps Script `saveNaverBatch`로 전송합니다.
- `매물ID`를 먼저 비교하고, 지번주소·층/호실·보증금·월세·평수가 모두 같은 기존 매물도 중복으로 제외합니다.
- 네이버 원본 상세페이지 주소를 시트1 Q열 `원본링크`에 함께 저장합니다.
- 네이버가 목록에서 지번을 숨긴 매물은 좌표를 Kakao Local API로 변환해 지번주소를 복구합니다.
- 수집 로직은 `my-map/js/naver-collector.js` 한 파일만 업데이트하면 집·사무실 PC에 동시에 반영됩니다.
