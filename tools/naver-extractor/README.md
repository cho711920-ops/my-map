# JS부동산 네이버 추출기 v2.1.1

네이버부동산에서 선택한 매물을 개별 저장하거나, 큰 클러스터의 여러 페이지를 끝까지 수집해 `NAVER_IMPORT` 시트에 저장하는 Edge/Chrome 확장프로그램입니다.

## 현재 Apps Script와의 호환성

- 현재 복원된 `NAVER_IMPORT` Apps Script `v2.1.0`의 `saveNaverBatch` 기능과 호환됩니다.
- Apps Script 코드는 교체하지 않아도 됩니다.
- 한 번에 200건 이상을 서버로 보내지 않고 30건씩 분할하여 저장합니다.

## 설치

1. `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. 기존 `JS부동산 네이버 추출기 v1.2.2`는 삭제하지 말고 먼저 사용 중지합니다.
4. `압축 풀린 항목 로드`를 누릅니다.
5. 이 폴더 안의 `extension` 폴더를 선택합니다.
6. 네이버부동산 탭을 완전히 새로고침합니다.
7. 확장프로그램 설정에 기존 Apps Script `/exec` URL과 접근키를 입력합니다.

## 사용

1. 네이버부동산에서 원하는 마커나 큰 클러스터를 누릅니다.
2. 확장프로그램을 열어 감지 건수를 확인합니다.
3. 큰 클러스터는 `클러스터 전체 불러오기`를 누릅니다.
4. 수집 완료 후 `전체 저장`을 누릅니다.
5. 저장은 30건씩 진행되며 신규·중복·실패 건수가 표시됩니다.

개별 매물은 각 카드의 `이 매물만 저장` 버튼으로 계속 저장할 수 있습니다.

## 안전장치

- 매물번호를 기준으로 수집 중복을 제거합니다.
- 최대 100페이지까지만 조회합니다.
- 같은 페이지가 반복되거나 새 매물이 없으면 자동 종료합니다.
- 저장 중 오류가 발생하면 성공한 묶음 다음부터 이어서 저장합니다.
- 현재 탭의 감지 정보만 사용하므로 다른 네이버 탭의 오래된 목록이 섞이지 않습니다.

## 주의

- 네이버 내부 응답 형식이 변경되면 페이지 수집 로직도 조정해야 할 수 있습니다.
- 현재 Apps Script의 중복 기준은 `지번주소 + 층·호실 + 보증금 + 월세`입니다.
- 화면에 노출된 카카오 REST API 키는 카카오 개발자센터에서 교체하는 것을 권장합니다.
