JS 통합 매물 수집기

버튼 하나로 네이버·당근·공실박스를 자동 감지합니다. 실행할 때마다 js-map.com의 최신 수집기를 불러오므로 다시 설치할 필요가 없습니다.

JS 매물 수집
  1. 위 JS 매물 수집 버튼을 브라우저 북마크바로 끌어놓습니다.
  2. 네이버페이 부동산·당근부동산·공실박스 지도 중 수집할 사이트를 엽니다.
  3. 북마크바의 JS 매물 수집을 누르고 구 또는 숫자 클러스터를 선택합니다.
  4. 완료 화면의 발견·신규·갱신·검증·실패 수와 완전수집 Y/N을 확인합니다.
네이버목록을 먼저 비교하고 신규·변경 매물만 상세조회합니다.
당근서버에 저장 지점을 보존하고 중단 후 이어서 진행합니다.
공실박스대량 클러스터를 나눠 읽고 응답속도에 따라 저장 묶음을 조절합니다.
최신 스크립트 위치: https://js-map.com/js/
